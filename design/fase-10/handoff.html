Qué es esto

De PROJECT_SPEC.md, sin resumir de más: un DAW de un solo usuario para grabar voz desde el teléfono (a menudo por auriculares), llevarla a una cadena DSP real, corregir tono, encajarla con un beat, mezclar y masterizar — sin estudio profesional. Enfoque de género: urbano/trap y estilos cercanos. Restricción dura que respeta todo el proyecto: el DSP puede compensar las limitaciones de un micrófono barato, pero no puede convertirlo en un micrófono de estudio — cada función debe ser honesta sobre eso.

Regla de desempate

La más importante para no repetir trabajo ya revertido una vez.

Si el texto de fase-10-reconstruccion-interfaz.md o REFERENCIAS-VISUALES.md contradice el archivo estudio-ui.html — por ejemplo, el doc menciona la tipografía "Archivo + JetBrains Mono" pero el archivo usa Bricolage Grotesque + Instrument Sans + DM Mono — gana el archivo. Así lo pide el brief original: "no es inspiración, es el destino". Ya se implementó con la tipografía del archivo.

Esta misma página usa esa tipografía y esos tres colores base (grafito/hueso/verde-señal) a propósito, para que se sienta como una extensión del propio sistema del proyecto, no un documento aparte.

Cómo se verifica cada cambio

El estándar ya establecido en 46 sesiones anteriores — no bajarlo.

  • 01Nunca "debería andar". Todo cambio visual se confirma con captura de pantalla o lectura real de la página en un navegador, después de recargar el dev server.
  • 02tsc --noEmit, eslint y vitest run (289 tests) limpios antes de cada commit. Un test que falla una vez y pasa al repetir es flaky, no una regresión — pero confirmalo repitiendo, no asumiendo.
  • 03Un subfase = un commit con mensaje que explica el porqué, no solo el qué. Push a claude/personal-ai-daw-s9v97w después de cada uno — no acumular cambios sin subir.
  • 04Si algo del archivo de referencia no se puede reproducir, decirlo con el motivo técnico concreto. Nunca sustituirlo en silencio por una versión más simple.

Un límite legal real

Se replica cómo funciona y qué muestra un plugin de referencia (FabFilter, iZotope, Soundtoys...), nunca su apariencia de marca. Prohibido copiar el aspecto distintivo, los colores propios, los logotipos o los nombres comerciales — ya se corrigió un caso real: el efecto de corrección de tono se llamaba "Auto-Tune" en la interfaz y se cambió a "Afinación".
